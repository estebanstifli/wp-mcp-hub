# Security policy

WP MCP Hub is currently an alpha project. Security fixes are applied to the
latest release only.

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature on the repository. Include the affected
version, platform, impact, reproduction steps, and any suggested mitigation.
Never include active credentials or production customer data.

The project will acknowledge a complete report within seven days and coordinate
disclosure after a fix is available. No response-time guarantee is made until a
maintainer security contact is published.
